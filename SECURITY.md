# Security Policy

## Reporting a vulnerability

Please **do not** disclose an unpatched security vulnerability in a public GitHub issue.

If GitHub private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option under the repository's **Security** tab. Otherwise, contact the maintainer through a private channel listed on their GitHub profile and request a secure way to share details. Do not include exploit details in public discussions.

Include the affected component and version, reproduction steps or proof of concept, impact, and suggested mitigation when possible. Never share real credentials or personal usage data.

## Supported versions

TokenBar is evolving across multiple platforms. Security fixes are generally targeted at the latest maintained release or default branch; older releases may not receive backports. Check [Releases](https://github.com/ChaconLucas/tokenbar/releases) for updates.

## Disclosure

Please allow the maintainer time to investigate and coordinate a fix before public disclosure. No guaranteed response or remediation timeline is promised.
