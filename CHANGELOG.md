# Changelog

This file tracks notable user-facing changes for future TokenBar releases.

TokenBar has previously published software through GitHub Releases. Historical release notes have **not** been reconstructed or verified in this file; do not interpret this document as evidence that every past release has release notes.

## Unreleased

### Added
- Contributor guidelines and a security reporting policy.

## Release notes policy

For each future release, add a section headed with its actual version and release date, summarizing notable added, changed, fixed, deprecated, and removed behavior as applicable. Describe breaking changes, migration steps, and upgrade impact. Identify publicly known runtime vulnerabilities fixed in the release (including CVE IDs when assigned), or state that none are known. Publish the same human-readable summary in [GitHub Releases](https://github.com/ChaconLucas/tokenbar/releases).

Do not publish unverified release dates, version identifiers, or vulnerability claims.
